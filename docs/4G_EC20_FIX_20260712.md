# 4G Quectel EC200A 修复（2026-07-12）

参考：`6.18.33_GMAC_PATCH_COMPILE_VERIFY_20260618.md` §H7 / 2026-06-24 成功路径。

## 结论
驱动 `option/qmi_wwan` 本来就在；缺的是 **EC20 开机时序**。

| 脚 | GPIO | 电平 |
|---|---|---|
| PWREN | gpiochip4 line 29 (GPIO4_D5) | 1 = 供电 |
| RESET | gpiochip1 line 2 (GPIO1_A2) | 0 = 退出复位 |
| PWRKEY | gpiochip4 line 25 (GPIO4_D1) | 低脉冲 1.5s 后保持高 |

## 修复
- `/usr/local/bin/ec20-init.sh` + `ec20-init.service`
- `/etc/modules-load.d/lpa-4g.conf`

## AT 注网测试（2026-07-12，SSH）

端口：`/dev/ttyUSB2`（响应正常）

| 命令 | 结果 | 含义 |
|---|---|---|
| AT / ATI | OK，Quectel **EC200A**，FW `EC200ACNDAR01A04M16` | 模组通信正常 |
| AT+GSN | `868703054731088` | IMEI 正常 |
| AT+CPIN? | `+CME ERROR: 10` | **SIM not inserted** |
| AT+CIMI / AT+CCID | CME ERROR 13/10 | 无 SIM |
| AT+CSQ | `99,99` | 未知/无信号（无 SIM 时常见） |
| AT+CREG? / CGREG? / CEREG? | `0,0` | 未注册网络 |
| AT+CGATT? | `0` | 未附着 PS |
| AT+CGDCONT? | `IP,"cmnet"` | APN 已有中国移动默认 |
| AT+QCFG="usbnet" | `1` | USB 网卡模式 ECM 类 |

接口：`usb0` UP（cdc_ether），尚无 IPv4（未拨号/无 SIM）。

### 结论
- **硬件+驱动+AT 栈：PASS**
- **注网：BLOCKED — 未插 SIM 或 SIM 未识别**
- 插 SIM 后建议：
  ```bash
  # ttyUSB2
  AT+CPIN?
  AT+CSQ
  AT+CREG?
  AT+COPS?
  # 中国移动示例
  AT+CGDCONT=1,"IP","cmnet"
  AT+CGACT=1,1
  # 或使用 nd5g / ModemManager
  ```
