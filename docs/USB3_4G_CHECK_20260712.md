# USB3.0 + 4G 检查（2026-07-12，SSH on 192.168.50.17）

策略：后续仅 SSH 增量修改，不整盘重刷。

## USB 3.0

### 结论：**控制器正常（host 软件栈 OK）**；当前无 SuperSpeed 外设实测吞吐

| 项 | 结果 |
|---|---|
| DWC3 `usb@fe800000` / `usb@fe900000` | `status=okay`, `dr_mode=host`, driver bound |
| xHCI | 两组：Bus2/Bus6 = **5000M (USB3)** root hub |
| 已连接设备 | 仅 USB2：`480M` hub + UDisk；NPU `2207:0019` 在 EHCI 480M |
| SuperSpeed 设备枚举 | **无**（未插 USB3 设备） |

`lsusb -t` 关键：

```text
Bus 002 ... xhci ... 5000M   # USB3 root hub present
Bus 006 ... xhci ... 5000M
Bus 007 ... ehci 480M -> hub -> UDisk 480M
```

验收建议：插真 USB3 盘到 Type-A/蓝口，确认 `lsusb -t` 出现 `5000M` 设备节点后再测 `dd` 吞吐。

## 4G 模块

### 结论：**驱动模块可加载，但硬件未枚举**（非缺 option/qmi 模块）

| 项 | 结果 |
|---|---|
| 内核模块 `option/qmi_wwan/cdc_mbim/usb_wwan/usbserial` | **可 modprobe 成功** |
| `lsusb` modem VID | **无** |
| `/dev/ttyUSB* / cdc-wdm* / wwan*` | **无** |
| PCIe EP | 仅 RC，link down（NPU noep 路径预期） |
| DT 电源 | `n4-pwren` fixed-clock regulator always-on；`vcc_gnss` fixed always-on |
| GPIO | `n4-pwren` **hi**；`vcc-gnss` debugfs 显示 **lo**（与 regulator state=enabled 不一致，需再查） |

DT：

```text
n4-pwren: regulator-fixed-clock, gpio0-9, always-on/boot-on, enable-active-high
vcc-gnss: regulator-fixed, gpio3-25, always-on/boot-on, enable-active-high
```

regulator sysfs `state` 对 always-on 节点 **不可写**（Permission denied），无法软件开关验证。

### 含义

- **不是** “没编进 option/qmi 驱动” 的问题（模块在且已注册 USB serial/wwan 驱动）。
- 当前是 **模组未出现在 USB/PCIe 总线上**：供电时序/硬件连接/复位脚/USB 口路由/模组未贴装或损坏 需硬件侧确认。
- 下一步：确认模组型号与接口（USB 还是 PCIe/UART）、原理图 `n4` 供电与 USB 走线；必要时示波器/万用表量 `n4-pwren`/`vcc_gnss` 实际电平与模组 VCC。
